Account & cloud sync

Email/password se account bana kar apna data Firebase Realtime Database mein save aur apne account se restore karein. App offline bhi local device par kaam karti hai.

Guest mode — data sirf isi device par save hoga

Automatic cloud sync
Har change ke baad online save; internet na ho to local save jari rahega.

Setup: Firebase Console mein Email/Password sign-in enable karein aur Realtime Database create karein. Database rules sirf signed-in user ko uske users/{uid} path tak access dein. API key ko secret na samjhein; database rules aur Authentication zaroori hain. Code mein FIREBASE_CONFIG object ke andar apni API key, Auth domain, Database URL, Project ID aur App ID paste karein; ya yahan fields bhar kar save karein. Login ke baad local aur cloud progress merge ho kar sync hoti hai.

Backup & restore

Apni local progress ki backup file rakhein. JSON backup mein password aur Firebase config include nahi hoga.

Offline use: data isi browser/device par save hota hai. Cloud sync tab chalega jab internet, Firebase config aur sign-in active hon. Device ya browser data clear karne se pehle backup export karein.
